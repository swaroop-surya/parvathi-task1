# 🚀 WebWise Studio — Bootstrap 5 UI Project

## 📌 Overview

WebWise Studio is a modern, responsive multi-page website built using **Bootstrap 5**.
The project focuses on exploring Bootstrap components and combining them into a clean, professional UI.

This project was developed as part of an internship task to demonstrate:

* UI composition skills
* Responsive design
* Effective use of Bootstrap components

---

## 🎯 Features

* Fully responsive design (mobile, tablet, desktop)
* Modern minimal UI with consistent layout
* Multi-page structure:

  * Home
  * About
  * Contact
* Bootstrap components used:

  * Navbar
  * Cards
  * Grid system
  * Carousel
  * Forms
  * Alerts
  * Buttons & utilities

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* Bootstrap 5 (CDN)
* Git & GitHub
